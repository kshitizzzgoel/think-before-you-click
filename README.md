# Think Before You Click

A hands-on cybersecurity awareness course for college students aged 18–25.

**Created by Kshitiz Goel · MCA 3C · VIPS (GGSIPU) · Enrollment No. 17817704425**

## What's inside
- 3 animated videos (campaign film, four scam tricks, what to do if scammed)
- Full 7-scene production storyboard
- Link Inspector and Password Lab (run in your browser, nothing is sent anywhere)
- UPI and payment safety tutorial, 2FA guides
- Spot the Scam simulator
- 10-question final exam with printable certificate

## Run it
Open `index.html` in any browser. No installation needed.
